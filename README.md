# AcadTrack

A web-based student records digitization and PEAC file tracking system.

AcadTrack centralizes student records and PEAC certification files in one secure place, replacing scattered paper files and Google Drive folders. Authorized staff can search and retrieve any record in seconds, and a built-in tracker automatically flags missing documents so the school stays accreditation-ready.

> **Note:** This is a functional pilot/demo built with placeholder data. It does not contain actual student records.

## Features

- Per-student record search and retrieval
- PEAC certification tracking page organized by year
- Unified tracker that flags missing files
- Role-based access control and activity logs via Supabase

## Tech Stack

- Supabase (database, auth, role-based access)
